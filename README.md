# Фразы на стенд

Карманная шпаргалка ведущего кейсовой игры Cloud.ru. Игра идёт 5–7 минут: гость тянет одну карточку, говорит, как бы решил ситуацию, ведущий называет вариант с оборота и предлагает снять код на обучающий материал. Заявку не выпрашивают.

Шпаргалка для человека, которому трудно импровизировать. Вслух читаются только фразы в ёлочках. Серый текст — пометки себе. На стенде режим «Я у стола» показывает одну реплику и кнопку дальше.

## Как запустить

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:43123](http://127.0.0.1:43123). На телефоне у стойки удобно добавить страницу на экран «Домой».

## Как вести игру

1. Позовите одной фразой. Если человек уже у стола, сразу к темам.
2. Три стопки: машинное обучение, облака, сертификация. Карточку гость берёт сам.
3. Прочитайте заголовок. Задайте один вопрос с экрана и досчитайте до четырёх.
4. Если тишина — дайте выбор из двух краёв этой карточки. Если ответ есть — один уточняющий, не интервью.
5. Скажите «Спасибо, так тоже решают», потом абзац с оборота, потом про код. Карточку верните в колоду.
6. Один человек играет один раз.

Куда уходит время: до минуты на выбор, минута на вопрос, две–три на ответ гостя, минута на оборот, десять секунд на прощание.

## Откуда кейсы

Тексты собраны из карточек игры, файла кейсов и механики. В механике указано 12 карточек, в наборе кейсов их 13 (6 + 4 + 3), в макете 26 страниц: лицо и оборот. Перед сменой сверьтесь с живой колодой.

Ответ гостя не обязан совпасть с оборотом. Регистрация на курс желательна и не обязательна.
