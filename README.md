# Фразы на стенд

Шпаргалка ведущего кейсовой игры Cloud.ru. Один экран: три категории, карточка с текстом для участника, учебный ответ с оборота, возможные ответы, вопросы с подсказками и призыв открыть QR. Игровой балл начисляется за переход по коду.

На конференции откройте [https://kedra1087-byte.github.io/frazi-na-stend/](https://kedra1087-byte.github.io/frazi-na-stend/) с телефона. В Safari: «Поделиться» → «На экран Домой». В Chrome: меню → «Добавить на главный экран».

## Как запустить локально

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Как вести игру

1. Выберите категорию и карточку, которую вытянул участник.
2. Дайте прочитать описание или прочитайте его вслух. Оборот пока не показывайте.
3. Задайте один вопрос из блока подсказок.
4. После ответа прочитайте подводку к финалу и учебный ответ.
5. Попросите открыть QR. Балл за переход на страницу, регистрация на курс не обязательна.

В наборе 13 карточек: 6 про машинное обучение, 4 про облака, 3 про сертификацию. В механике указано 12. Перед сменой сверьтесь с колодой.
